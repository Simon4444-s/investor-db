# Číselník sektorů a fází

Definováno 2026-10-11 před sběrem dat (PLAN.md, kap. 5, krok 7). Jde o naši volbu, ne o převzatou klasifikaci.
Do polí `sektory_deklarovane`, `sektory_portfolio` a `investice.sektor` se zapisují jen kódy z tohoto číselníku.

## Sektory

| Kód | Sektor | Patří sem např. |
|-----|--------|-----------------|
| ai | AI a data | strojové učení, datové platformy, analytika |
| software | B2B software a SaaS | podnikový software, nástroje pro vývojáře, produktivita |
| fintech | Fintech a pojišťovnictví | platby, bankovnictví, investice, insurtech |
| zdravi | Zdraví a life sciences | medtech, biotech, digitální zdraví, farmacie |
| energie | Energetika a klima | cleantech, obnovitelné zdroje, úspory energie, ESG |
| mobilita | Mobilita a doprava | elektromobilita, sdílená doprava, automotive |
| prumysl | Průmysl, výroba a robotika | Industry 4.0, robotika, nové materiály, hardware |
| spotrebitel | Spotřebitelé a e-commerce | e-shopy, marketplace, spotřební produkty, foodtech pro spotřebitele |
| media | Média, zábava a hry | gaming, obsah, kreativní průmysl |
| vzdelavani | Vzdělávání | edtech |
| nemovitosti | Nemovitosti a stavebnictví | proptech, contech |
| agri | Zemědělství a potraviny | agritech, potravinářská technologie |
| bezpecnost | Kybernetická bezpečnost | |
| obrana | Obrana a bezpečnost státu | defence tech |
| vesmir | Vesmír | space tech |
| web3 | Blockchain a kryptoaktiva | |
| prace | HR a práce | nábor, správa zaměstnanců |
| logistika | Logistika a dodavatelské řetězce | |
| generalista | Bez sektorového zaměření | investor uvádí, že investuje napříč sektory |
| ostatni | Ostatní | nic z výše uvedeného; do poznámky se uvede, co přesně |

Když investor deklaruje sektor, který odpovídá více kódům, zapíší se všechny odpovídající kódy.

## Fáze

`pre-seed`, `seed`, `A`, `B+` (série B a pozdější), `growth`, `buyout`.
